# Для моей Леси ♡

Небольшой адаптивный сайт заботы: чек-лист, заметки о самочувствии, таймер питья, экспорт трёх напоминаний на следующий день в календарь и медицинская памятка со ссылками на источники.

Статический HTML/CSS/JS без сборки, аналитики, сторонних библиотек и передачи данных о здоровье на сервер. Заметки сохраняются в localStorage браузера. Кнопка внизу удаляет локальные данные. Репозиторий и GitHub Pages публичны; личных медицинских записей в репозитории нет.

Для просмотра: `python -m http.server 8765` и открыть http://localhost:8765.

Публикация: GitHub Pages → Deploy from a branch → main → / (root).

Таймер работает, пока страница открыта и активна. Фоновая работа и уведомления на заблокированном телефоне не гарантируются. Для уведомлений вне страницы импортируйте .ics в календарь и проверьте настройки уведомлений календаря. События создаются на завтра в 11:00, 15:00, 19:00 по часовому поясу устройства.

Памятка для взрослых проверена 17 ноября 2026. Не является диагностикой или индивидуальным назначением. Эпидемиологический блок — статическая сводка за 2–8 ноября 2026 по бюллетеню НИИ гриппа; не обновляется автоматически. Источники доступны во вкладке «Что поможет».
